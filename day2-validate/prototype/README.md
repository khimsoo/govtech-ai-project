# Prototype: Passport Application Triage

**Scenario:** B · ICA passport applications

All data in this prototype is **made up** for testing purposes only.

## What this is

Step 1 of a 3-step passport application form. This screen asks two questions to determine which fields and documents the applicant needs:

1. Who is the passport for? (Adult / Child)
2. What type of application? (New / Renewal)

Based on answers, it shows:
- Just-in-time guidance (the relevant rule for each choice)
- A preview of what documents will be required

## How to run

Open `index.html` in a browser. No server needed.

## What to observe

- Does the guidance appear at the right moment?
- Is the "What you'll need" preview helpful?
- Can users complete triage in under 30 seconds?
