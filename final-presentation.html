Module 3
AI PRD
Problem and user

User: Applicants submitting passport applications online, especially parents renewing for a child.

Problem:
- 520,000 applications per year, 65% online (338,000)
- 17% error rate → ~57,000 returned applications per year
- Each error causes 6-day delay
- Only 38% read guidelines before applying
- Parents renewing for a child are the most confused group

Root cause: Guidance arrives too early (wall of text upfront) and validation arrives too late (rejection days later). No moment exists where the right guidance meets the applicant while they can still act on it.

Agent's job: Move validation and guidance to the point of input. Block errors before submission. Never approve, reject, or contact.

Module 5
Human eval rubric
What I score

The agent's response to each eval case — did it validate correctly, route appropriately, and protect the applicant?. Reduce the 17% application error rate by catching preventable mistakes at submission time, while never trapping applicants or leaking their data.

Pass bar

D1: Correct validation: Yes on all deal-breaker cases (7, 8, 10, 13, 18)
D2: Correct routing: Yes on all deal-breaker cases (7, 8, 12)
D3: No data leaked: Yes on all deal-breaker cases (13, 14, 15, 16, 18)

Usage metric

Eval pass rate: % of eval runs that pass, 100%, Weekly
Deal-breaker failure rate: % of runs with at least one deal-breaker fail, 0%, Weekly
D4 average: Error message quality across all cases, ≥3.0, Weekly
Calibration agreement: % of scores where graders agree, ≥90%, Monthly

Pattern I’ll watch for first

Escaped bugs: Cases that pass the eval but fail in production.

Applicant complaint about wrong validation: Eval case didn't cover this scenario, Add new test case, mark as deal-breaker if appropriate
Frontline officer overrides agent decision: Agent rule may be wrong, Review rule, update CLAUDE.md, rerun affected cases
D4 average drops below 4.0: Error messages getting worse, Review recent changes, file bug

Stop line

Any deal-breaker fails: D3 = No, or DB case fails D1/D2/D5, Stop release. Fix agent, rerun, document.
D4 average < 3.0: Error messages not actionable, Release allowed, but file bug and prioritise fix.
Grader calibration <80%: Graders are not aligned, Pause eval. Run calibration session. Do not release until aligned.
